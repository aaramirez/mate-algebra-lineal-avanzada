# Álgebra lineal avanzada

La estructura de los operadores lineales y la geometría del producto interno: espacio dual, la función determinante, valores propios, Cayley-Hamilton y forma de Jordan, Gram-Schmidt y proyecciones, teorema espectral, formas bilineales y cuadráticas, valores singulares, pseudoinversas, mínimos cuadrados y una primera mirada a los espacios de Hilbert.

**Ver en línea:** https://aaramirez.github.io/mate-algebra-lineal-avanzada/
